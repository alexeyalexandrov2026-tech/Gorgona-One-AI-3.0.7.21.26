- No API key, booking API, local payment processing, customer-data transfer, database migration or background catalogue scraper is introduced.
- Interface controls and section headings cover all sixteen existing languages through `headoutCopy.mjs` and `experienceCopy.mjs`. Headout titles remain as supplied. Original Viator link labels in `viatorEditorial.mjs` have English and Russian versions; the remaining locales use the English label. Provider widgets retain their English/USD configuration; supplier content is not claimed to be fully translated.
- The existing search readers now return actual Headout collections instead of the previous demonstration experiences. Supplier content is excluded from the owned translation inventory. Retired Stores categories are removed from Discovery navigation and the sitemap.
