## B. nextShowcaseStep — port verbatim (lib/heroShowcase.js:126-157)
```js
export const MOBILE_CORNERS = ['tl', 'tr'];
const ENTERS = ['swing', 'rise', 'focus', 'slide'];
const EXITS = ['outUp', 'outDown', 'outFade', 'outSide'];
export function cornerSide(corner) { return corner.endsWith('l') ? 'L' : 'R'; }
export function nextShowcaseStep(pool, state, rnd = Math.random, mobile = false) {
  if (!pool.length) return null;
  const used = new Set(state?.used || []);
  if (pool.every((item) => used.has(item.href))) used.clear();
  const available = pool.filter((item) => !used.has(item.href));
  const source = available.length ? available : pool;
  let categories = [...new Set(source.map((item) => item.cat))].filter((cat) => cat !== state?.lastCat);
  if (!categories.length) categories = [...new Set(source.map((item) => item.cat))];
  const cat = categories[Math.floor(rnd() * categories.length)];
  const items = source.filter((item) => item.cat === cat);
  const item = items[Math.floor(rnd() * items.length)];
  used.add(item.href);
  const corners = (mobile ? MOBILE_CORNERS : DESKTOP_CORNERS).filter((corner) => {
    if (!state?.lastCorner) return true;
    return corner !== state.lastCorner && cornerSide(corner) !== cornerSide(state.lastCorner);
  });
  const corner = (corners.length ? corners : (mobile ? MOBILE_CORNERS : DESKTOP_CORNERS))[Math.floor(rnd() * (corners.length || (mobile ? 2 : 6)))];
  const enters = ENTERS.filter((name) => name !== state?.lastEnter);
  const enter = enters[Math.floor(rnd() * enters.length)];
  const exit = EXITS[Math.floor(rnd() * EXITS.length)];
  const side = cornerSide(corner);
  const rot = `${((rnd() * 7) + 2) * (side === 'L' ? -1 : 1)}deg`;
  return { item, corner,
    enter: enter === 'slide' ? (side === 'L' ? 'slideL' : 'slideR') : enter,
    exit: exit === 'outSide' ? (side === 'L' ? 'outL' : 'outR') : exit,
    rot, state: { lastCat: cat, lastCorner: corner, lastEnter: enter, used } };
}
```
App uses mobile=true only (corners tl/tr, strictly alternating). Random draw order: category, item, corner, enter, exit, rot.
Inject the random source (e.g. `() -> Double`) so tests are deterministic. State is immutable (return new).
In RTL, 'l' means the start side (mirror positions and slide/rotation directions).

## C. Showcase timing & motion
- First step: nextShowcaseStep(items, empty state). Reduced motion (follow however the app already detects
  "reduce motion", e.g. animator duration scale = 0): show items[0], corner tr, rot 4°, no timer, static.
- Show for intervalMs (6500), then exit 700 ms, then the next step enters over 900 ms. Pause the timer while the app
  is not RESUMED and while the card is pressed. No catch-up.
- Enter easing cubic-bezier(0.2,0.7,0.2,1); exit cubic-bezier(.6,0,.6,1). Blur optional (skip below API 31; alpha
  is enough).
  swing: 0% α0, y -26dp, rot r+14 → 45% α1, rot r-5 → 70% rot r+2.5 → 100% α1, y0, rot r
  rise: α0, y +34dp → α1, y0
  focus: α0, scale .86 → α1, scale 1
  slideL/slideR: α0, x ∓46dp → α1, x0 (L = negative)
  outUp: → α0, y -22dp ; outDown: → α0, y +26dp ; outFade: → α0, scale .92 ; outL/outR: → α0, x ∓40dp
- Pivot = top centre, 15dp down; base rotation = rot (deg). Optional hanging-tag hole: 12dp circle 15dp from top.

## D. Showcase card (app version — decision: readable on 360dp, NOT the site's .6 scale)
- Width 148dp, over the Today hero photo at top-start / top-end, ~10dp inset. Radius 16/16/22/22dp. Padding
  26/12/11dp. Background = the app's existing card colour token; ink / ink-soft from the app theme. Soft shadow.
- Content top→bottom: image 3:2, radius 9dp, crop, Coil; eyebrow (small uppercase mono-style: label + bold aside,
  #EDD49C on dark / accent on light); title (display font, max 2 lines); CTA in accent colour, dashed top rule, small
  arrow (mirrored RTL); thin progress bar at bottom (gold→accent) over intervalMs, hidden under reduced motion.
  Skip the site's detail rows to keep it compact.
- Per cat: car → "Car" + (company or "Our fleet"); CTA = price (+ " / day" unless it already contains "day") when
  showcasePrice is valid, else "Rates on request". yacht → "Yacht" + (length or company); CTA "Charter on request".
  stay → "Stay" + "{n} bedrooms" if n>0 (proper plurals); CTA "Rate on request". jet → "Boarding" + "Any route";
  CTA "Search flights". event → "Tickets" + kicker; title = kicker or title; CTA "Get tickets".
  showcasePrice: trimmed string; must match /\$\s?\d/ and NOT /request|enquir|inquir/i, else null.
- Whole card clickable → router.open(item.href). Content description = visible text.
- Eyebrow/CTA strings in 16 languages: first look for them in origin/main's i18n catalogue (i18n/source.json,
  i18n/locales/*.js; likely home.showcase.* / home.tickets.*) and import via the strings import script; otherwise
  write natural translations. Use Android plurals for bedrooms if the strings pipeline supports it, otherwise
  separate one/many keys.

## E. Data layer: core/ShowcaseApi.kt
- Follow existing HTTP/JSON patterns (core/SearchApi.kt, PlanApi.kt; MockTransport in tests).
- GET {siteBase}/api/showcase; parse; drop invalid items (same rules as the API). Cache last good response on
  device using whatever persistence the app already uses. Offline/error → cache; no cache → no card. intervalMs from
  response, default 6500, clamp 3000..20000. Fetch when Today first appears and on resume if older than 10 min.

## F. Section rail: today/SectionRail.kt (uses the shared HomeSections object from block 1)
- Placement: top of Today, under the header, above the hero. Row = track + pause button at end (start in RTL).
- Tile 148dp wide, min 84dp tall, radius 14dp, bg #15242D, photo fill (Coil, crop, site base URL + path), bottom
  overlay gradient rgba(5,14,21,.94) → rgba(5,14,21,.08) at 86%; label at bottom, white, weight 600, ~15sp, 16dp
  arrow (mirrored RTL). Gap 10dp, track padding 4dp.
- Concierge tile: no photo; radial background (#2E2A20 at 50%/30% → #14232C 55% → #0A1218), 1dp border #3B4144,
  label #FFF8E2; gold orb 30dp at top centre, 8dp from top: radial #FFF8E2 0% → #F3D477 18% → #D4AF37 42% → #8A681E
  68% → #1A1305 100% with soft glow; gentle float, off under reduced motion. Tap → AI tab.
- exclusive → Exclusive tab; events → Events screen (same routing as the ☰ menu); others → router.open(href).
- Auto-scroll 25 dp/s, frame-based (cap dt at 100 ms), infinite loop (render twice or wrap; second copy hidden from
  accessibility). RTL reverses direction.
- Stops: pause toggled; reduced motion (no drift, pause button hidden); app not RESUMED; rail off-screen; touch,
  drag or fling → hold 6 s after the last interaction, then resume from the current position; accessibility focus
  inside the rail. Pause button: 44dp circle, 48dp touch target, border, card bg, pause bars / play triangle,
  content description "Pause"/"Play" in 16 languages.
- Test tags: rail, rail.tile.<id>, rail.pause.
