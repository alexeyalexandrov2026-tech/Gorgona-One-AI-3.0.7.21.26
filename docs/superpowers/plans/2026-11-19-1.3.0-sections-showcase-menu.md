# Miami Elio Android 1.3.0: лента разделов, плавающие карточки, меню, «Эксклюзивные направления»

Дата: 19 ноября 2026. Ветка приложения `claude/android-app-agent-rr0ij5`. Рабочая версия в Play — 1.2.2 (код 6).

## Что попросил владелец (19 ноября)

1. Клавиатура «выскакивает постоянно, когда заходишь» и мешает. На эмуляторе с 1.2.2 не воспроизведена
   (`mInputShown=false` на всех вкладках) — экран у владельца не уточнён.
2. «Вверху нету меню, оно внизу… человек не видит его» — нужно меню, которое видно.
3. В нижнем меню вместо «События» — «Эксклюзивные направления»; сами события не терять.
4. «Движущиеся рамки разделов нашего сайта вверху» — лента разделов, как на главной сайта.
5. «Вернуть плавающие рамки… постоянно появлялись… аренда машин, поездка… всё, менялось постоянно» — карточки
   `HeroShowcase` сайта.
6. «Скинь мне скриншоты, когда всё сделаешь, перед тем как продакшн выставлять».

## Решения

- Данные карточек — **новый адрес сайта `/api/showcase`** (выбор владельца, 19 нояб.). Отдельная ветка сайта
  от `origin/main`, PR вливает владелец.
- События — со строки «Ближайшее…» на «Сегодня» и пунктом верхнего меню (вариант по умолчанию; владелец не
  ответил на вопрос, можно поменять).
- «Эксклюзивные направления» — страница сайта `/exclusive-destinations` во вкладке (по умолчанию).
- Меню ☰ вверху + нижнее меню (по умолчанию).
- В Play ничего не выкладывается без снимков и «да» владельца.

## Как это сделано на сайте (origin/main)

- Лента разделов: `app/components/home/HomeSectionRail.jsx`, данные `lib/homeData.js` → `HOME_SECTIONS`
  (11 карточек: travel `/travel`, exclusive `/exclusive-destinations`, stays `/vacation-rentals`, yachts `/yachts`,
  cars `/rentals`, events `/events`, privateJets `/private-jets`, experiences `/experiences`, adventures
  `/entertainment/adrenaline-365`, dining `/restaurants-nightlife`, concierge `/discovery` без фото — шар AI).
  Прокрутка `RAIL_SPEED_PX_PER_S = 25` через `requestAnimationFrame`, кнопка паузы, стоп при касании,
  при `prefers-reduced-motion` и скрытой вкладке.
- Плавающие карточки: `app/components/home/HeroShowcase.jsx`, логика `lib/heroShowcase.js`
  (`SHOWCASE_INTERVAL_MS = 6500`, `MOBILE_CORNERS = ['tl','tr']`, входы `swing|rise|focus|slide`, выходы
  `outUp|outDown|outFade|outSide`, `nextShowcaseStep` не повторяет категорию и угол подряд), данные
  `lib/heroShowcaseData.js` → `buildHeroShowcase()` (машины, яхты, виллы, билеты на события, джет), собирается
  сервером внутри `app/page.js`; отдельного адреса нет. Анимации — `app/design-system.css` `g1-sc-*`.
- Поиск `/api/search` для этого не годится: яхт, джетов и событий в нём нет (проверено 19 нояб.).

## Часть 1. Сайт: `/api/showcase`

- Отдельный worktree `…\Miami Elio\miami-elio-showcase-api`, ветка `feat/api-showcase` от свежего `origin/main`
  (правила `CLAUDE.md` сайта; ничего не брать из старых веток).
- `app/api/showcase/route.js`: `GET` → `{ intervalMs: 6500, items: [...] }` из `buildHeroShowcase()`; поля
  элемента: `cat` (`car|yacht|stay|jet|event`), `href`, `title`, `image` (абсолютный https), `price?`,
  `company?`, `length?`, `location?`, `bedrooms?`, `category?`, `kicker?`, `lineId?`. Кэш
  `public, s-maxage=600, stale-while-revalidate=3600`. Только чтение, без персональных данных.
- Тест рядом с `tests/content/hero-showcase.test.mjs`: форма ответа, только https-фото, без пустых `href`.
- Проверка: тесты сайта, `next build`; PR открывается и вливается владельцем.

## Часть 2. Приложение

1. **Лента разделов** (`today/SectionRail.kt`) вверху «Сегодня», под шапкой: те же 11 карточек и порядок, фото
   с сайта через Coil (кэш), подписи — из каталога переводов сайта скриптом (как `import-home-copy.mjs`),
   автопрокрутка 25 dp/с, пауза, стоп при касании, статично при «уменьшить движение». Нажатие → `router.open(href)`;
   карточка AI → вкладка AI.
2. **Плавающие карточки** (`today/Showcase.kt` + `core/ShowcaseApi.kt`): `/api/showcase`, кэш последнего ответа
   на устройстве (работает без сети), смена каждые 6,5 с, те же входы/выходы, углы `tl/tr` поверх фото героя;
   нажатие → `router.open(href)`. Порт `nextShowcaseStep` с тестами. Нет данных — карточки нет.
3. **Нижнее меню**: Today · Catalog · AI · **Exclusive** · Profile. Вкладка «Exclusive» — свой
   `WebTabController` со стартом `/exclusive-destinations`. Экран «События» остаётся (`EventsScreen`), открывается
   со строки на «Сегодня» и из верхнего меню; «назад» с него — на «Сегодня».
4. **Меню ☰ вверху** на «Сегодня», «Каталоге», AI, «Событиях»: список — Today, Catalog, AI concierge, Exclusive
   destinations, Events, Profile и разделы сайта (те же 11 из `HOME_SECTIONS`).
5. **Клавиатура**: при смене вкладки и при возврате в приложение снимать фокус и прятать клавиатуру
   (`LocalFocusManager.clearFocus()`, `LocalSoftwareKeyboardController.hide()`); уточнить у владельца экран.
6. Новые строки — через `android/strings.json` → `build-strings.mjs`, все 16 языков.
7. Тесты: лента (порядок, нажатие, пауза, без движения при reduce motion), карточки (смена, порядок углов,
   офлайн-кэш, нажатие), меню (все пункты ведут куда надо), нижнее меню (5 слотов, Exclusive), клавиатура.
   Снимки 360×740: `today-en/ru/he` с лентой и карточкой, `menu-open-en`, `exclusive-en`, `events-from-today-en`.
