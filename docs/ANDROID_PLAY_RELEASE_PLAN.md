## 2. Блокеры публичного выпуска

1. **Политика конфиденциальности (`/privacy`) не годится для Google Play.** Сейчас там три абзаца: общая фраза про «структуры для аналитики, партнёрского отслеживания и монетизации», текст про чат «в этой вкладке браузера» (в приложении не так), жалоба на ответ и диктовка. Нет: кто оператор и как связаться; какие данные собираются (имя, почта, телефон, даты и состав поездки, аккаунт, избранное, сообщения консьержа, жалобы); кому передаются (Supabase, Cloudflare и поставщик ИИ, Telegram для уведомлений команды); сроки хранения; порядок удаления; возраст. Google требует, чтобы политика соответствовала ответам в Data safety. Черновик текста — раздел 6. Правка сайта — отдельная задача через ветку от `main` и PR.
2. **Приёмка сервера на тестовой учётной записи не проведена** (`docs/ANDROID_RELEASE_SERVICES.md`): повтор заявки возвращает те же ID, чужой аккаунт не видит чужого, избранное гостя переходит в аккаунт, жалоба видна администратору, репетиция удаления аккаунта. Нужна отдельная тестовая учётная запись (создаёт владелец) и согласие на тестовую заявку — она уйдёт уведомлением команде в Telegram.
3. **Аккаунт для проверяющего Google** (раздел «Доступ к приложению»): «Моё Майами» требует входа. Логин и пароль создаёт и вводит владелец.
4. **Тип аккаунта разработчика.** Если «Gorgona One AI» — личный аккаунт, созданный после 13.11.2023, для рабочего выпуска нужен закрытый тест: не меньше 12 тестировщиков 14 дней подряд, затем заявка на доступ к рабочей версии. Для аккаунта организации этого нет. Проверить: Play Console → Настройки → Аккаунт разработчика.

## 3а. Аналитика в приложении — решение и важная находка (14 ноября)

Владелец выбрал: полная политика + не грузить Cloudflare Web Analytics в приложении. Ветка **`feat/privacy-android-beacon`** (`4b468ae6`) = `feat/privacy-policy-android` + компонент `app/components/AnalyticsBeacon.jsx` (не грузит счётчик при `MiamiElioApp/` в User-Agent или `data-app="android"`), контакт `support@gorgona-one.com`. Сливается в `main` (`c2fda0fc`) без конфликтов, меняет только политику, переводы, `app/layout.js` и тест. PR не открыт: `gh` не авторизован, браузеры без входа в GitHub.

**Находка:** на живом сайте счётчик вставляет сам Cloudflare на своей стороне (автоматическая установка Web Analytics: `beacon.min.js/vce…`, `data-cf-beacon` с `version 2024.11.0`, токен `fc0790156d184ab3a8aa664be86189ad` — публичный), а переменная `NEXT_PUBLIC_CLOUDFLARE_WEB_ANALYTICS_TOKEN` при сборке не задана. Поэтому компонент сам по себе счётчик в приложении **не уберёт**. Нужно в панели Cloudflare: (1) Web Analytics → сайт `gorgona-one.com` → выключить автоматическую вставку; (2) в настройках сборки сайта (Workers Builds) добавить переменную `NEXT_PUBLIC_CLOUDFLARE_WEB_ANALYTICS_TOKEN` с этим токеном и пересобрать. Проверка после: в обычном браузере на странице есть `static.cloudflareinsights.com/beacon.min.js`, а с User-Agent, содержащим `MiamiElioApp/1.0`, — нет (страницу проверять в браузере: скрипт добавляется после загрузки). Пока это не сделано, фраза политики «в Android-приложении нет аналитики» неверна.

**Сделано 14 ноября (с согласия владельца, через Chrome):** в настройках сборки Worker `gorgonaoneai3072126` добавлена переменная `NEXT_PUBLIC_CLOUDFLARE_WEB_ANALYTICS_TOKEN` (проверено после перезагрузки). Web Analytics для `gorgona-one.com` переключена с «Enable, excluding visitor data in the EU» на «Enable with JS Snippet installation» — владелец согласился, что после этого будут учитываться и посетители из ЕС. Проверено: в живом HTML и в браузере счётчика больше нет нигде. Открыт PR [#57](https://github.com/alexeyalexandrov2026-tech/Gorgona-One-AI-3.0.7.21.26/pull/57) из `feat/privacy-android-beacon`, проверки зелёные. **До вливания PR #57 сайт не считает посещения;** после вливания и сборки: в обычном браузере счётчик есть, с `MiamiElioApp/1.0` в User-Agent — нет (проверить в браузере).

## 4. Черновик ответов Data safety («Безопасность данных»)

Основа: код приложения (нет SDK аналитики, рекламы и сбоев; разрешения `INTERNET`, `ACCESS_NETWORK_STATE`, `RECORD_AUDIO`, `MODIFY_AUDIO_SETTINGS`, `POST_NOTIFICATIONS`, `RECEIVE_BOOT_COMPLETED`) и страницы сайта, открытые в приложении. «Передача» (sharing) по правилам Google не включает обработчиков, действующих от имени разработчика (Supabase, Cloudflare, поставщик ИИ, Telegram для уведомлений своей команды).

- Собирает ли приложение данные: **Да**. Передаёт третьим лицам: **Нет** (только обработчики).
- Шифрование при передаче: **Да** (только HTTPS; перенаправление на http запрещено).
- Способ запросить удаление: **Да** — `https://gorgona-one.com/account/delete`.
- Создание аккаунта: на сайте внутри приложения (Supabase Auth) — уточнить способы входа по живой форме.
