# Шаг 6: внутренний TestFlight и проверка на iPhone

Состояние на 11 ноября 2026: **подготовлено, ждёт аккаунта Apple Developer.** Цель шага — поставить приложение на настоящий iPhone через TestFlight (только для своих, без проверки Apple) и проверить то, что на симуляторе не проверить: диктовку и напоминания сезона.

## Что уже готово

- **Выгрузка в TestFlight** — workflow `.github/workflows/ios-release.yml`. Запускается меткой `ios-testflight-<версия>` на нужном коммите любой ветки, поэтому сливать №43 в `main` (и выкладывать сайт) для этого не нужно. Кнопка «Run workflow» в GitHub появится только после слияния — GitHub показывает её лишь для workflow из `main`. Сборки по метке помечаются «только для внутреннего тестирования»: их нельзя случайно отдать внешним тестировщикам или отправить в App Store.
- **Номер сборки** — номер запуска workflow и попытки (`12.1`), поэтому повторный запуск не упрётся в «такой номер уже был».
- **Проверка сборки без подписи на каждом изменении `ios/`** — job `release-archive` в workflow iOS собирает Release так же, как перед выгрузкой, и проверяет то, на чём App Store Connect отклоняет первую сборку (`ios/scripts/check-release-archive.sh`): версия и номер сборки доходят до приложения; bundle ID `com.miamielio.app`; отметка «шифрование только стандартное» (`ITSAppUsesNonExemptEncryption = NO`, иначе каждая сборка ждёт ручного ответа); объяснения для микрофона, распознавания речи и камеры; иконка (1024×1024, без прозрачности); манифест приватности; файл сезона.

Без аккаунта не проверить: подпись, саму выгрузку и обработку сборки в App Store Connect. При первом запуске возможны правки workflow.

## Что сделать владельцу (после активации Apple Developer, около 30 минут)

Ключи и пароли в чат не присылать — только в настройки GitHub (пункт 6).

1. **Аккаунт Apple Developer** — 99 $ в год, developer.apple.com/programs. После оплаты Apple включает аккаунт от нескольких часов до двух суток. Аккаунт на компанию требует номера D-U-N-S и идёт дольше; от него зависит, чьё имя будет продавцом в App Store.
2. **Team ID** — developer.apple.com → Account → Membership details: 10 символов.
3. **Идентификатор приложения** — Certificates, Identifiers & Profiles → Identifiers → «+» → App IDs → App: описание «Miami Elio», Bundle ID — Explicit, `com.miamielio.app`. Галочки в Capabilities не ставить: напоминания локальные, push не нужен. Если Apple скажет, что идентификатор занят, напишите мне — поменяю его в проекте.
4. **Приложение в App Store Connect** — appstoreconnect.apple.com → Приложения → «+» → Новое приложение: iOS; название «Miami Elio» (если занято — например «Miami Elio Concierge»; под иконкой на телефоне всё равно будет «Miami Elio»); основной язык; Bundle ID `com.miamielio.app`; SKU `miamielio-ios`.
5. **Ключ API** — Пользователи и доступ → Интеграции → App Store Connect API → Ключи команды → «+»: имя «GitHub TestFlight», доступ **Admin** (с меньшими правами сборка не сможет сама получить сертификат). Скачать файл `AuthKey_….p8` — Apple даёт скачать его один раз. Записать Key ID и Issuer ID.
6. **Секреты в GitHub** (нужен вход) — репозиторий → Settings → Secrets and variables → Actions → New repository secret, четыре штуки: `APPLE_TEAM_ID`, `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8` (всё содержимое файла `.p8`, вместе со строками `BEGIN` и `END`).
7. **Группа тестировщиков** — App Store Connect → приложение → TestFlight → Внутреннее тестирование → «+»: группа «Команда», добавить себя (тот Apple ID, что на iPhone; он должен быть в «Пользователях и доступе»), включить автоматическую раздачу сборок.
8. **Написать мне «выпускай».** Я ставлю метку `ios-testflight-1.0.0` на последний коммит ветки №43. В `main` ничего не попадает, сайт не меняется. Через 20–40 минут (сборка на GitHub плюс обработка у Apple) придёт письмо из TestFlight.
9. **На iPhone** — поставить приложение TestFlight из App Store, открыть приглашение, установить Miami Elio. Сборка TestFlight работает 90 дней.

## Проверка на iPhone

Перед началом: язык сайта — в «Главной», переключатель языка сайта; консьерж и диктовка берут язык оттуда. Если что-то не так — снимок или запись экрана, модель iPhone, версия iOS, язык и время.

### Диктовка (вкладка «Консьерж», кнопка микрофона справа от поля)

| № | Что сделать | Что должно произойти | ✓ / ✗ |
|---|---|---|---|
| Д1 | Первый раз нажать микрофон | Два системных вопроса: распознавание речи («Miami Elio преобразует ваш голосовой запрос в текст для консьержа») и микрофон («…когда вы диктуете запрос консьержу…»). Разрешить оба | |
| Д2 | Сказать по-русски «Яхта на субботу на шестерых» | Кнопка становится золотым шаром со знаком «стоп», шар растёт в такт голосу, в поле написано «Слушаю…», слова появляются по мере речи | |
| Д3 | Нажать шар | Микрофон выключается, текст остаётся в поле, сам **не отправляется** | |
| Д4 | Отправить стрелкой | Ответ консьержа приходит только текстом, вслух ничего не читается | |
| Д5 | Набрать «Вилла», затем надиктовать «на неделю» | В поле «Вилла на неделю» — сказанное добавилось к набранному | |
| Д6 | Включить микрофон и молчать минуту | Через 60 секунд выключается сам | |
| Д7 | Во время диктовки перейти на другую вкладку; ещё раз — свернуть приложение | Микрофон выключается, сказанное остаётся в поле | |
| Д8 | Переключить сайт на английский, затем на иврит, надиктовать фразу | Распознаёт на выбранном языке | |
| Д9 | Режим полёта, надиктовать по-русски | Если iPhone умеет распознавать этот язык без сети — работает; если нет — строка «На этом iPhone голосовой ввод для этого языка недоступен.» Приложение не зависает | |
| Д10 | Настройки iPhone → Miami Elio → выключить микрофон; нажать микрофон в консьерже | Строка «Чтобы говорить с консьержем, разрешите микрофон и распознавание речи в Настройках.» и кнопка «Настройки», которая открывает настройки приложения | |
| Д11 | Включить VoiceOver, навести на кнопку | Читает «Произнесите ваш запрос»; во время диктовки — «Остановить» | |
| Д12 | Настройки → Универсальный доступ → Движение → «Уменьшение движения»; надиктовать | Шар не меняет размер, только яркость | |

### Напоминания сезона (вкладка «Консьерж», блок «Сезон Майами» под тремя готовыми запросами)

Напоминание приходит в 10:00 по Майами (зимой это 18:00 по Москве, с 14 марта 2027 — 17:00) за три недели до начала. Если три недели уже прошли — на следующее утро, но не в день начала; если и это поздно, колокольчика у недели нет. Ближайшие даты:

| Неделя | Напоминание за 3 недели | Позже — «на следующее утро» до |
|---|---|---|
| Art Basel Miami Beach, 4–6 декабря | 13 ноября | утра 3 декабря (после — колокольчика нет) |
| New Year's Eve, 31 декабря | 10 декабря | утра 30 декабря |
| Miami International Boat Show, 10–14 февраля 2027 | 20 января | утра 9 февраля |
| Miami Open, 14–28 марта | 21 февраля | утра 13 марта |
| Ultra Music Festival, 26–28 марта | 5 марта | утра 25 марта |
| Formula 1 Miami Grand Prix, 30 апреля – 2 мая | 9 апреля | утра 29 апреля |

| № | Что сделать | Что должно произойти | ✓ / ✗ |
|---|---|---|---|
| С1 | Открыть консьержа, пролистать ниже готовых запросов | «Сезон Майами»: недели с ближайшей, у каждой дата, место и «через N дней» / «Завтра» / «Идёт сейчас» | |
| С2 | Нажать колокольчик у ближайшей недели | Первый раз — системный вопрос об уведомлениях; разрешить. Колокольчик золотой, в строке «Напомним <дата>» — дата по таблице выше | |
| С3 | Нажать колокольчик ещё раз, потом снова | Напоминание снимается и ставится заново | |
| С4 | Закрыть приложение (смахнуть), заблокировать телефон, дождаться времени | Уведомление: заголовок «Art Basel Miami Beach · Dec 4 – 6» (название и даты — по-английски, как на сайте), текст «Недели, которые раскупают первыми…» | |
| С5 | Нажать на уведомление | Открывается вкладка «Консьерж», в поле уже написан запрос «Art Basel Miami Beach, Dec 4 – 6. Помогите спланировать: машина, жильё, ужин и билеты.» — сам **не отправляется** | |
| С6 | Поставить напоминание на другую неделю, перезагрузить iPhone | После перезагрузки в строке по-прежнему «Напомним …», уведомление приходит в срок | |
| С7 | Если в момент напоминания приложение открыто | Баннер всё равно показывается сверху | |
| С8 | Настройки iPhone → Miami Elio → Уведомления → выключить; открыть консьержа | Строка «Уведомления Miami Elio выключены…» и кнопка «Настройки» | |
| С9 | Нажать на строку недели (не на колокольчик) | Консьержу сразу уходит запрос «спланировать» эту неделю, ответ приходит текстом | |

Остальное, что стоит проверить на iPhone до отправки в App Store (вход, заявка, фото партнёра, частные самолёты, ссылки на партнёров, работа без сети), — в `docs/APP_STORE_READINESS.md`, пункт 4.
